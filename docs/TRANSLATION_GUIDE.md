# 카무라이(KHAMRAI) 번역 지침

## 파일 형식
- 원문: `text/src/sNN.tsv` — `번호<TAB>일본어`. `#FILE 이름` 줄은 어느 스크립트 파일인지 알려 주는 주석(번역 파일에 쓰지 않아도 됨).
- 번역: `text/ko/sNN.tsv` — `번호<TAB>한국어`. 원문의 모든 번호를 빠짐없이, 한 줄에 하나씩.
- UTF-8, 탭 하나로 구분.

## 반드시 지킬 것
1. **제어 코드 보존**: `%M0`~`%M9`, `%C0`~`%C7`, `%W1` 등 `%`+영문+숫자 코드는 글자 그대로 남긴다. `%C2아이템명%C7`처럼 색 코드로 감싼 단어는 번역어도 감싼다.
2. **끝의 `%` 보존**: 원문이 `%`로 끝나면 번역도 반드시 `%`로 끝난다. 원문이 `%`로 끝나지 않으면(예: 스태프롤, 지명 목록) 번역도 `%`로 끝내지 않는다.
3. **줄 길이**: 제어 코드를 뺀 보이는 글자 수(공백 포함, 한글·기호 모두 1자)가 **17자 이하**(대사창이 17자를 넘으면 자동 줄바꿈하여 아래 줄과 겹침). 빌드 시 `tools/reflow.py`가 같은 대사의 연속 줄 사이에서 단어를 재배치한다.
4. **줄 구조**: 원문 한 줄 = 번역 한 줄. 한 대사가 여러 줄(연속 번호)에 걸쳐 있으면 의미를 줄 사이에서 자연스럽게 재배치해도 되지만 줄 수는 그대로.
5. **문장부호**: 이 게임 글꼴에서 `☆`는 느낌표(!), `★`는 물음표(?)로 표시된다. 원문처럼 `☆`, `★`를 그대로 쓰고, `!` `?`(반각/전각) 대신 `☆` `★`를 쓴다. `☆☆` 같은 반복도 원문대로.
   - 말줄임표는 원문의 `・・・`를 그대로 쓴다. 마침표 `.`는 쓰지 않는다(문장 끝 마침표 생략).
   - 쉼표는 `,`(반각)를 쓴다. 따옴표 「」『』, 물결 `～`, 장음 `ー`, 괄호（）는 원문처럼 사용 가능.
   - 띄어쓰기는 일반 공백(반각 스페이스) 하나.
   - 쓸 수 있는 문자: 한글 완성형, 숫자(전각 ０-９ 또는 원문 그대로), 위 문장부호, 원문에 있던 기호(▲■△▼○ 등은 감정 아이콘이므로 그대로 둔다).
   - 한자·가나·라틴 알파벳은 쓰지 않는다(원문에 ＷＩＬＬ·Ｌｖ 같은 전각 영문이 있으면 그대로 둬도 됨).
6. **기계 번역 금지**: 직접 맥락을 읽고 자연스러운 한국어로 번역한다. 캐릭터 말투(반말/존댓말, 고어체 등)를 살린다.
7. 디버그/테스트용 문장(テスト, セレクト 메뉴 등)도 번역한다. `\SRC\...` 같은 경로는 원문 파일에 없음(이미 제외됨).

## 말투
- 카가토: 활발한 소년 주인공, 반말. 「俺」→ 나.
- 슈온: 소녀, 친근한 반말·여성 말투.
- 키리하: 당찬 여성, 반말("~야", "~해").
- 유: 가벼운 소년, 반말.
- 츠키카게: 「我」를 쓰는 고풍스러운 무사 말투 → "나는 ~하겠다", "~이로다" 정도로 위엄 있게.
- 사요히메: 공주, 정중한 존댓말("~해요", "~합니다").
- 오바바: 노파, "~이란다", "~거라".
- 신왕·신장: 위엄 있는 하오체/하게체 또는 "~느니라".
